# SkillSquare

SkillSquare is a simple landing page for a skills-focused platform. It presents a polished "Launching Soon" experience with a dark-mode toggle, email signup interaction, and feature highlights.

## Project overview

This repository contains a single-page HTML site built with:

- HTML
- CSS
- Vanilla JavaScript

## Files

- `index.html` — the complete landing page and app logic

## How to run

Because this is a static HTML page, you can open it directly in a browser:

1. Clone the repository
2. Open `index.html` in your browser

Alternatively, you can serve it locally with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Modern landing page design
- Light/dark theme toggle
- Email signup validation
- Responsive layout for mobile and desktop
